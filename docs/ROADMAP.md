# Дорожная карта проекта Sirin VPN (Roadmap)

В данном документе зафиксированы ключевые направления развития клиентских приложений, протокола ядра и серверной инфраструктуры Sirin VPN.

---

## 🎯 Текущий статус по компонентам

### 1. Router Client (OpenWrt)
- [x] **v1.0.0**: Базовый full tunnel и встроенный RuDirect (4945 CIDR).
- [x] **v1.1.0–v1.1.2**: Веб-интерфейс LuCI, поддержка PPPoE WAN, автоопределение шлюза, автозапуск procd.
- [x] **v1.2.0**: Настраиваемое раздельное туннелирование (режимы Bypass и Only, произвольные CIDR, доменные имена, 8641 CIDR в RuDirect, атомарная загрузка в nftables sets).
- [x] **v1.3.0–v1.4.0**:
  - XHTTP+Reality транспорт (Router v1.3.0).
  - Раздельное туннелирование по портам (Router v1.4.0): направление выбранных портов (например, 80/443) через VPN, поддержка диапазонов и протоколов (`tcp:80`, `udp:27000-27050`), режим Gaming Bypass.
- [x] **v1.5.0**:
  - Автономная сборка пакетов `.ipk` (OpenWrt <= 24.x, `opkg`) и `.apk` (OpenWrt >= 25.x, `apk`) для 5 архитектур (`mips`, `mipsle`, `armv7`, `arm64`, `x86_64`) + `all`/`noarch` для LuCI.
  - All-in-one пакеты `sirin-full` для установки клиента и веб-интерфейса в один клик.
  - Подготовлены официальные Makefiles для OpenWrt SDK (`openwrt/sirin-client/Makefile`, `openwrt/luci-app-sirin/Makefile`).
- [x] **v1.6.0**:
  - **Аварийный резервный канал Whitelist Fallback (WebRTC TURN VK Calls / DION / S3)**:
    - Обход тотальных блокировок внешнего интернета и протоколов через национальные белые списки (VKontakte, OK.ru, DION / ВТБ).
    - Анонимная добыча WebRTC TURN токенов из ссылок VK Calls (`vk.com/call/join/...`) и комнат DION (`dion.vc/event/...`) без аккаунтов.
    - Автоматический откат лестницы (`auto`) или принудительный режим работы только через белый список (`always`).
    - Управление в LuCI Web UI (`luci-app-sirin`) и десктопном клиенте.
  - **Встроенный модуль Anti-DPI (обход замедления YouTube и Discord без VPN)**:
    - Просмотр YouTube 4K/8K и голосовые вызовы Discord на максимальной скорости провайдера через WAN без расхода трафика внешнего VPN-сервера.
    - Встроенный чистый Go-прокси прозрачной фрагментации первого пакета TLS ClientHello (разбиение SNI) для обхода фильтрации ТСПУ.
    - Принудительный сброс QUIC (UDP 443 reject) для мгновенного отката клиентов на TCP/TLS HTTP/2.
    - Автоматическая синхронизация через dnsmasq и ядерные динамические nftables ipsets (`antidpi_cidrs`).
    - Управление и диагностика в LuCI Web UI (`luci-app-sirin`).
  - **Резервный канал Dead Drop (Яндекс Диск / S3-совместимые хранилища)**:
    - Автоматический переход на Dead Drop при блокировке ТСПУ центрального сервера конфигурации `/v1/params`.
    - Поддержка публичных ссылок Яндекс Диска с автоматическим двухшаговым резолвингом через официальное REST API Яндекса без авторизации.
    - Поддержка S3 хранилищ (VK Cloud Object Storage, Yandex Cloud S3).
    - Локальное энергонезависимое кеширование параметров (Zero-Downtime Resilience).
    - Интеграция в Web UI LuCI и десктопный клиент.
  - **OpSec & Network Stack Hardening (по методике Vektor T13)**:
    - Нормализация TTL пакетов на выходе из туннеля (маскировка роутера и раздачи трафика).
    - Автоматический TCP MSS Clamping под MTU туннеля для устранения "черных дыр" MTU.
    - Anti-DNS-Leak: принудительный перехват порта 53 UDP/TCP в локальный dnsmasq.
    - Блокировка DNS-over-TLS (DoT, порт 853) для закрытия обхода Android Private DNS.
    - Управление через веб-интерфейс LuCI (`luci-app-sirin`) и `rpcd/sirin`.
- [ ] **v1.7.0** *(В планах)*:
  - Локализация LuCI UI на несколько языков (gettext).

### 2. Android Client
- [x] **v1.0.0–v1.1.0**: Базовая работа с TUN, защита от утечек IPv6, интеграция с Telegram-ботом.
- [x] **v1.2.0**: Поддержка динамической ротации пула SNI (VK CDN, Кинопоиск, WB, IKEA, Microsoft).
- [x] **v1.3.0**: Полный редизайн интерфейса в кибер-стиле («Крипто-защита», неоновая палитра Cyber-Neon, интерактивная кнопка питания, статус-бар уведомления Material Design).
- [ ] **v1.4.0** *(В планах)*:
  - Выбор приложений для Split Tunneling по категориям.
  - Графический монитор скорости и расхода трафика в реальном времени.
  - Быстрый переключатель узлов прямо из шторки уведомлений (Quick Settings Tile).

### 3. Windows Desktop Client
- [x] **v1.0.0**: Клиент на базе Wails с поддержкой Windows TUN, автозапуска и системного трея.
- [x] **v1.1.0**:
  - RuDirect: встроенные 8641 RU-диапазон RIPE NCC через высокоскоростной Win32 IP Helper API (`CreateIpForwardEntry2`).
  - Раздельное туннелирование по доменам и IP-диапазонам (режимы `Bypass` и `Only`).
  - Расширенные настройки в Wails UI: тумблер RuDirect, выбор режима, редактирование списков доменов и CIDR.
- [ ] **v1.2.0** *(В планах)*:
  - Синхронизация визуального стиля с мобильным клиентом Android (Cyber-Neon).
  - Автоматическое обновление приложения (In-app Updater).

### 4. Apple iOS / iPadOS Client
- [x] **Spike & Архитектура**: Завершено исследование сетевого стека iOS ([`docs/SPIKE_IOS.md`](SPIKE_IOS.md)).
- [ ] **Фаза 1 (Q1 2027)**: Packet Tunnel Provider на базе Swift + Go Mobile (XCFramework).
- [ ] **Фаза 2 (Q2 2027)**: Интерфейс на SwiftUI и распространение через TestFlight.

### 5. Server & Bot Infrastructure
- [x] Автосинхронизация ключей между Telegram-ботом и VPN-демоном `sirind`.
- [x] Ротация SNI для обхода блокировок ТСПУ.
- [ ] Интеграция биллинга и платежных шлюзов (Telegram Stars, криптовалюта, СБП).
- [ ] Автоматические уведомления пользователей об окончании срока действия подписки.
- [ ] Развёртывание многосерверной сети с автоматическим балансировщиком нагрузки (Anycast / GeoDNS).
