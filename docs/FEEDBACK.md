# Руководство по обратной связи и диагностике (Sirin Router)

Если вы столкнулись с проблемой при установке, настройке или работе клиента Sirin VPN на роутере OpenWrt, следуйте данной инструкции для сбора диагностической информации и отправки отчёта.

## 2. Сбор диагностических данных на роутере

Перед отправкой баг-репорта выполните следующие команды по SSH на роутере и приложите их вывод.

> [!WARNING]
> Никогда не публикуйте ваш настоящий персональный UUID (`password` в `client.toml`). Перед отправкой замените его на `REDACTED`!

### 2.1. Статус службы и последние логи

```bash
# 1. Проверка состояния процесса
/etc/init.d/sirin status

# 2. Получение JSON-статуса через ubus
ubus call sirin status

# 3. Последние записи системного журнала
logread | grep sirin | tail -n 50
```

### 2.2. Проверка сетевого интерфейса и маршрутов

```bash
# Проверка наличия и MTU виртуального интерфейса sirin0
ip addr show dev sirin0

# Проверка VPN-маршрутов (/1)
ip route show | grep -E '0.0.0.0/1|128.0.0.0/1'

# Проверка split tunneling (RuDirect): маршрут к российскому ресурсу должен идти через WAN (eth0/wan0), а не sirin0
ip route get 77.88.8.8
```

### 2.3. Проверка бэкенда веб-интерфейса (RPCD)

```bash
# Список зарегистрированных методов объекта sirin
ubus -v list sirin

# Тест сквозной связности и определения внешнего IP
ubus call sirin test_connection
```

### 2.4. Диагностика в браузере (LuCI Web UI)

Если проблема связана с отображением или работой веб-интерфейса:
1. Откройте панель разработчика в браузере: нажмите `F12` (или `Ctrl+Shift+I`) и перейдите на вкладку **Console**.
2. Перейдите на вкладку **Network** и профильтруйте по `/ubus`.
3. При воспроизведении проблемы (например, нажатие кнопки «Сохранить») проверьте:
   - Есть ли ошибки JavaScript в Console.
   - Какой HTTP-код возвращает запрос `/ubus` (должен быть `200 OK`).
   - Если код `403 Forbidden`, обновите сессию LuCI или перезапустите службу `rpcd`:
     ```bash
     /etc/init.d/rpcd restart
     ```

## 3. Частые проблемы и решения (FAQ)

### 3.1. Ошибка: `/dev/net/tun не найден`
- **Причина:** В системе не загружен модуль ядра для работы с TUN-интерфейсами.
- **Решение:**
  - На OpenWrt 24.x (`opkg`):
    ```bash
    opkg update && opkg install kmod-tun
    ```
  - На OpenWrt 25.x / SNAPSHOT (`apk`):
    ```bash
    apk update && apk add kmod-tun
    ```

### 3.2. Служба запускается и сразу останавливается
- **Причина:** Не указан или повреждён персональный ключ (`password`) в `/etc/sirin/client.toml`.
- **Решение:** Убедитесь, что в конфиге вписан корректный UUID v4:
  ```bash
  grep "password" /etc/sirin/client.toml
  # Ключ должен быть валидным UUID v4: xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx
  ```

### 3.3. В LuCI не отображается пункт меню «Sirin VPN»
- **Причина:** Не очищен кэш меню LuCI после первой установки.
- **Решение:**
  ```bash
  rm -rf /tmp/luci-indexcache /tmp/luci-modulecache
  /etc/init.d/rpcd restart
  ```
  После этого обновите страницу в браузере с очисткой кэша (`Ctrl+F5`).
