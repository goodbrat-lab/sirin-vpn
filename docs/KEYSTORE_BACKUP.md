# Регламент резервного копирования Production Keystore (Sirin Android)

## 1. Общие сведения

Android-приложение Sirin VPN начиная с версии `android-v1.3.5` подписывается постоянным закрытым 4096-битным RSA-ключом.

> [!CAUTION]
> **Критическая важность:**
> Если файл `sirin-release.jks` будет утерян, выпускать обновления приложения станет **невозможно навсегда**. Пользователям придётся удалять приложение с потерей настроек. Храните резервные копии надёжно!

---

## 2. Места хранения закрытого ключа

В соответствии с правилом «3-2-1» хранилище `sirin-release.jks` дублируется в 3 независимых местах:

1. **Локальный рабочий ПК (хост разработчика):**
   - Каталог: `C:\Antigravity_project\keys\sirin-release.jks`
   - Локальные реквизиты (пароль и алиас): `C:\Antigravity_project\keys\keystore_info.txt`
   *(Каталог находится вне git-репозитория и защищён от случайного коммита).*
2. **Личное облачное хранилище владельца:**
   - Зашифрованный архив `sirin-keys-backup.7z` (алгоритм AES-256) в защищённом облаке владельца.
3. **Физический внешний носитель (Flash-накопитель):**
   - Офлайн-копия на съёмном диске в сейфе/хранилище владельца.

---

## 3. Секреты в CI/CD (GitHub Actions)

В репозитории `goodbrat-lab/sirin-vpn` (Settings → Secrets and variables → Actions) настроены 4 секрета:
- `KEYSTORE_BASE64`: base64-представление бинарного файла `sirin-release.jks`.
- `KEYSTORE_PASSWORD`: пароль к хранилищу.
- `KEY_ALIAS`: алиас ключа (`sirin`).
- `KEY_PASSWORD`: пароль к закрытому ключу.

CI-пайплайн (`.github/workflows/build-apk.yml`) автоматически декодирует ключ при сборке тегов `android-v*`. При отсутствии любого из секретов сборка прерывается (fail-fast).

---

## 4. Верификация отпечатка сертификата

Для проверки подлинности ключа используйте утилиту `keytool` из состава JDK:
```bash
keytool -list -v -keystore C:\Antigravity_project\keys\sirin-release.jks -alias sirin
```

### Эталонные характеристики сертификата:
- **Владелец / Издатель:** `CN=Sirin VPN, OU=Release, O=Sirin Project, L=Moscow, C=RU`
- **Алгоритм:** RSA 4096-bit (SHA384withRSA)
- **Срок действия:** до 2054 года
- **SHA-256 отпечаток:**
  `0E:1B:85:C4:C7:EB:50:EA:58:6A:1C:09:A4:07:D4:8B:A6:26:B5:7B:DF:D7:91:BE:EC:84:81:40:35:BB:FD:A6`

Для проверки собранного APK:
```bash
apksigner verify --print-certs app-release.apk
```
Отпечаток `SHA-256` должен строго совпадать с указанным выше.
