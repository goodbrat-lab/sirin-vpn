# Матрица принятия решений (Decision Matrix)

Правила классификации проблем и критерии выпуска релизов по итогам фидбэка первой волны.

---

## 1. Критерии выпуска релизов

### Патч-релизы (Hotfix / 48 часов)
- **router-v1.1.2** / **Android v1.2.1** / **Windows v1.0.1**:
  - Условие: хотя бы один подтвержденный и воспроизводимый `severity/blocker`.
  - Примеры: падение LuCI, полное отсутствие интернета при подключении, краш сервиса/приложения при старте.
  - SLA выпуска: не более **48 часов** с момента подтверждения воспроизведения (repro).

### Минорные релизы (Feature / 1–2 недели)
- **router-v1.2.0** / **Android v1.3.0** / **Windows v1.1.0**:
  - Условие: накопление $\ge 3$ подтвержденных дефектов `severity/major` или $\ge 5$ приоритизированных `type/enhancement`.
  - Примеры: проблемы совместимости с нестандартными темами LuCI, оптимизация reconnect, улучшение UX ошибок.
  - SLA выпуска: **1–2 недели** плановой разработки с предварительным тестированием в контейнере/эмуляторе.

### Режим «Пауза» (Стабилизация)
- Если в течение **2 недель** зафиксировано:
  - 0 проблем с меткой `severity/blocker`
  - $\le 3$ проблем с меткой `severity/major`
- Действие: объявляется временная заморозка текущих платформ, фиксация стабильного ядра и переход к разработке клиентов для **macOS / Linux**.

### Мажорный релиз (v2.0)
- Условие: $\ge 5$ крупных архитектурных улучшений (`type/enhancement`) и не менее **1 месяца** непрерывной стабильной эксплуатации текущего поколения.

---

## 2. Правила эскалации и принятия решений

1. **Единоличное решение:** окончательное решение о классификации severity, отклонении (`wontfix`) или переносе в следующий майлстоун принимает только мейнтейнер проекта (@goodbrat).
2. **Публичный статус:** статус любого запроса отражается исключительно через GitHub Labels (`severity/*`, `needs-info`, `wontfix`).
3. **Обратная связь пользователю:**
   - Если репорт отклоняется (`wontfix`), в комментарии к Issue дается развернутое техническое обоснование.
   - Если запрошены логи (`needs-info`), ожидание ответа составляет до 7 дней, после чего тикет переводится в архив.
