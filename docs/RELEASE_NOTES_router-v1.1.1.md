# Release Notes: Sirin Router v1.1.1

## Sirin Router v1.1.1

### Новое
- **LuCI-приложение luci-app-sirin**: веб-интерфейс для управления клиентом прямо из браузера (статус службы, настройки шлюза и ключей, MTU, RuDirect, сквозная диагностика подключения и встроенный просмотр журнала работы).
- **Автоматическая установка UI**: установщик `install.sh` автоматически определяет наличие LuCI и ставит компоненты интерфейса (поддерживаются флаги принудительного включения `--with-ui` и отключения `--no-ui`).
- **Строгая валидация UUID v4**: проверка формата персонального ключа на бэкенде RPCD и динамические подсказки в интерфейсе LuCI при сохранении.
- **Адаптивный дизайн**: поддержка тем LuCI (`Bootstrap`, `Argon`, `OpenWrt 2020`) и мобильной верстки для смартфонов (от 360px).

### Исправлено (критично)
- **Маскирование пароля в LuCI**: устранена ошибка awk-парсинга в `/usr/libexec/rpcd/sirin`, из-за которой при сохранении формы маскированный ключ `69c8e325...` мог перезаписать реальный UUID в `/etc/sirin/client.toml`.
- **Создание директорий**: исправлено создание родительской папки конфига через `dirname "$CONFIG_FILE"`.

### Требования
- OpenWrt 24.10.x (`opkg`) или OpenWrt 25.x (`apk`)
- Модуль ядра `kmod-tun` и пакет `nftables`
- LuCI (опционально, требуется для работы веб-интерфейса)

### Установка (SSH на роутер)

```bash
wget -O - https://raw.githubusercontent.com/goodbrat-lab/sirin-vpn/master/apps/router/install.sh | sh
```

После установки веб-интерфейс доступен по адресу:
`http://<ip-роутера>/cgi-bin/luci/admin/services/sirin` (меню **Службы** → **Sirin VPN**).

### Известные ограничения
- Протестировано в изолированных контейнерах OpenWrt 24.10.8 (`opkg`), OpenWrt 25.12.6 (`apk`) и SNAPSHOT на x86_64; для физических роутеров на MIPS/ARM собирается обратная связь.
- Тема Argon протестирована на OpenWrt 24.10 с пакетом `luci-theme-argon` v3.0.0 (страница и контролы открываются корректно).
- Локализация интерфейса: русский язык (мультиязычность i18n запланирована в будущих версиях).
