# Трекер распространения первой волны (Rollout Tracker)

Таблица учета раздачи сборок первой волны тестирования Sirin (Android, Windows, Router).

## Правила первой волны

1. **Изоляция:** каждому пользователю предоставляется доступ **только к одной платформе** на первом этапе, чтобы локализовать платформозависимый фидбэк.
2. **Квота:** минимум 2 пользователя на каждую целевую платформу (Android, Windows, Router).
3. **Фиксация проблем:** при любом выявленном баге или сбое обязательно указывать ссылку на соответствующий GitHub Issue в колонке «Замечания».

## Возможные статусы

- `sent` — ссылка и ключ доступа отправлены пользователю.
- `installed` — приложение / пакет установлено на устройстве.
- `working` — подключение успешно проверено (IP сменился, интернет работает).
- `issues` — возникли проблемы или ошибки (указана ссылка на Issue).
- `inactive` — пользователь не вышел на связь в течение 48 часов.
