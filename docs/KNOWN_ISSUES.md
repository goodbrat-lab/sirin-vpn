# Известные проблемы (Known Issues — Sirin)

Реестр подтвержденных особенностей, ограничений и известных дефектов для сборок первой волны.

> [!NOTE]
> **Правило ведения:** перед каждым релизом обновлять соответствующий раздел. Обязательно давать ссылки на открытые или закрытые задачи с метками `wontfix` (архитектурные ограничения) или `needs-repro` (плавающие проблемы).

## Router (v1.1.1)
- **Конфликт с прозрачными прокси (sing-box / tproxy / xray):** при одновременном запуске sing-box с правилами перехвата tproxy/redirect исходящие пакеты Sirin (UDP 56005, TCP 443) заворачиваются обратно в sing-box. Симптом: клиент запускается, создаёт sirin0, пишет «Подключение к шлюзу: ...» и зависает. Решение: остановить `/etc/init.d/sing-box stop`.
- **PPPoE и имя WAN-интерфейса:** если в `/etc/sirin/client.toml` было жёстко задано `wan_interface = "wan"`, при подключении через PPPoE сокет привязывался к физическому интерфейсу `wan` вместо туннельного `pppoe-wan`. В обновлении интерфейс определяется автоматически по таблице маршрутов по умолчанию (`ip route show default`).
