# Чеклист верификации установки и LuCI Web UI (Sirin Router v1.1.1)

Данный чеклист предназначен для проверки работоспособности клиента Sirin VPN и веб-интерфейса `luci-app-sirin` на реальном устройстве с OpenWrt 24.x (`opkg`) или 25.x (`apk`).

---

## 1. Установка через one-liner

- [ ] Выполнить на роутере:
  ```bash
  wget -O - https://raw.githubusercontent.com/goodbrat-lab/sirin-vpn/master/apps/router/install.sh | sh
  ```
- [ ] Убедиться, что скрипт корректно определил архитектуру процессора (`mips`, `mipsle`, `armv7`, `arm64`, `x86_64`).
- [ ] Убедиться, что скрипт обнаружил LuCI и вывел:
  ```text
  Installing LuCI Web UI...
  UI: http://<router-ip>/cgi-bin/luci/admin/services/sirin
  ```
- [ ] Проверить наличие установленных файлов:
  ```bash
  ls -la /usr/bin/sirin-client
  ls -la /etc/init.d/sirin
  ls -la /etc/sirin/client.toml
  ls -la /usr/libexec/rpcd/sirin
  ls -la /usr/share/rpcd/acl.d/luci-app-sirin.json
  ls -la /usr/share/luci/menu.d/luci-app-sirin.json
  ls -la /www/luci-static/resources/view/sirin/overview.js
  ```

---

## 2. Проверка работы RPCD-бэкенда (CLI)

- [ ] Запросить список поддерживаемых методов:
  ```bash
  ubus -v list sirin
  ```
- [ ] Проверить метод `status`:
  ```bash
  ubus call sirin status
  # Ожидается: {"running":false,"enabled":true,"pid":0,"version":"1.1.0","transport":"","uptime_sec":0}
  ```
- [ ] Проверить чтение конфигурации:
  ```bash
  ubus call sirin get_config
  ```
- [ ] Проверить диагностику сети:
  ```bash
  ubus call sirin test_connection
  ```

---

## 3. Проверка через веб-интерфейс LuCI

- [ ] Открыть в браузере: `http://192.168.1.1/cgi-bin/luci/admin/services/sirin`
- [ ] Убедиться, что в боковом меню появился пункт **Службы** → **Sirin VPN**.
- [ ] **Карточка «1. Состояние службы»:**
  - [ ] Отображается бейдж «Остановлен» (жёлтый/красный).
  - [ ] Версия клиента отображается как `1.1.1`.
  - [ ] Кнопка «Запустить» активна, кнопка «Остановить» неактивна.
- [ ] **Карточка «2. Настройки подключения»:**
  - [ ] Вставить персональный UUID из Telegram-бота `@sirin_crp_bot`.
  - [ ] Нажать кнопку «Показать / Скрыть» для проверки отображения пароля.
  - [ ] Нажать «Сохранить» → должно появиться модальное окно с предложением «Перезапустить службу Sirin?».
  - [ ] Выбрать «Да, перезапустить».
- [ ] **Проверка перехода в активное состояние:**
  - [ ] В течение 5 секунд бейдж статуса меняется на зелёный «Работает (PID: ...)».
  - [ ] Отображается активный транспорт (`UDP` или `VLESS`).
  - [ ] Счётчик времени работы (`uptime`) начинает увеличиваться.
- [ ] **Карточка «3. Диагностика и мониторинг»:**
  - [ ] Нажать «Проверить подключение» → отображается публичный IP вашего VPS и статус `RuDirect напрямую через WAN (ок)`.
  - [ ] Нажать «Показать логи» → открывается модальное окно с записями журнала работы, кнопка «Обновить» перезапрашивает свежие строки.

---

## 4. Проверка устойчивости и автозапуска

- [ ] Перезагрузить роутер (`reboot`).
- [ ] После включения роутера открыть LuCI и убедиться, что служба автоматически поднялась в статус «Работает».
- [ ] Проверить выход в интернет с подключённого клиента (ноутбук/телефон по Wi-Fi).
- [ ] Проверить раздельный маршрут:
  ```bash
  ip route get 77.88.8.8 | grep -q sirin0 && echo "FAIL" || echo "OK"
  ```

---

## 5. Проверка безопасности маскирования пароля и валидации UUID

- [ ] Открыть страницу настроек `http://<router-ip>/cgi-bin/luci/admin/services/sirin`.
- [ ] Убедиться, что сохранённый ключ отображается в виде маски `69c8e325...`.
- [ ] Не меняя поле пароля, изменить другой параметр (например, флаг RuDirect) и нажать «Сохранить».
- [ ] Проверить файл `/etc/sirin/client.toml`:
  ```bash
  grep "password" /etc/sirin/client.toml
  ```
  Убедиться, что настоящий UUID сохранён, а не перезаписан строкой с многоточием (`...`).
- [ ] Попробовать ввести некорректный UUID (например, `abc-123`):
  - [ ] Под полем ввода появляется предупреждение: `Формат ключа отличается от стандартного UUID v4`.
  - [ ] Сохранение разрешено (с предупреждением в RPCD `warn: не похоже на UUID v4`).
- [ ] Попробовать стереть ключ полностью и нажать «Сохранить»:
  - [ ] LuCI / RPCD возвращает ошибку `password: пустой ключ` и не даёт очистить пароль.

## 6. Проверка сохранения конфигурации при обновлении (Upgrade Paths)

- [ ] Обновление с v1.0.0 (без UI) на v1.1.1:
  - Существующий файл `/etc/sirin/client.toml` остаётся нетронутым.
  - Поля `gateway`, `password`, `device_id` и массив fallback-узлов `[[ladder]]` сохраняются полностью.
  - Создаётся резервная копия `/etc/sirin/client.toml.bak.<timestamp>`.
- [ ] Обновление с v1.0.1 на v1.1.1:
  - Запуск `install.sh` обновляет бинарник `/usr/bin/sirin-client` и компоненты LuCI без сброса настроек.

---

## 7. Проверка совместимости тем оформления и мобильного интерфейса

- [ ] **Тема Bootstrap (стандартная OpenWrt):**
  - Разметка форм и таблиц отображается ровно без наложений.
  - Кнопки действий окрашены в стандартные цвета (`cbi-button-action`, `cbi-button-reset`, `cbi-button-positive`, `cbi-button-negative`).
- [ ] **Сторонние темы (Argon, OpenWrt 2020):**
  - Поддержка нативной структуры `cbi-map` / `cbi-section` / `cbi-value`.
  - Корректная контрастность текста и бейджей статуса в тёмном режиме (Dark Mode).
- [ ] **Мобильный интерфейс (Mobile Viewport 360–414px):**
  - Блоки параметров вертикально стекаются (`flex-direction: column`).
  - Поля ввода и кнопки занимают полную ширину контейнера, исключая горизонтальный скролл.
  - Модальные окна («Логи», «Подтверждение перезапуска») не выходят за границы экрана.

---

## 8. Проверка авторизации и доступа ACL (JSON-RPC /ubus)

- [ ] В сессии обычного непривилегированного пользователя без прав `luci-app-sirin` RPC-вызовы возвращают `Access Denied` (403).
- [ ] В сессии администратора (`root`):
  - Вызовы `sirin status`, `sirin get_config`, `sirin set_config` выполняются успешно через HTTP `/ubus`.
  - В логах `/var/log/messages` отсутствуют ошибки `ubus: access denied`.
