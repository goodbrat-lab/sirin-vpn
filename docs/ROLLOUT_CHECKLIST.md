# Pre-rollout Checklist: Sirin Router v1.1.1

Чеклист готовности релиза `router-v1.1.1` перед открытой раздачей пользователям.

---

### Статус проверок

- [x] **v1.1.1 собран и опубликован (5 архитектур):**
  - MIPS, MIPSLE, ARMv7, ARM64, x86_64 собраны через GitHub Actions CI/CD.
  - Релиз `router-v1.1.1` и архивы доступны на GitHub Releases.
- [x] **ACL и ubus работают (200 OK, не 403 Forbidden):**
  - Проверено в OpenWrt через HTTP POST `/ubus` с сессионным токеном.
  - Все методы (`status`, `get_config`, `set_config`, `start`, `stop`, `restart`, `get_logs`, `test_connection`) авторизованы.
- [x] **Маскирование пароля исправлено и проверено:**
  - Парсинг ключа в awk исправлен через `match($0, /"[^"]*"/)`.
  - Сохранение настроек с маской `69c8e325...` не перезаписывает реальный UUID в `client.toml`.
  - Fallback-массив `[[ladder]]` сохраняется без повреждений.
- [x] **UUID v4 валидация работает:**
  - Регулярное выражение UUID v4 на бэкенде RPCD.
  - Пустой ключ блокируется с ошибкой `password: пустой ключ`.
  - Не-UUID ключ сохраняется с предупреждением `warn: не похоже на UUID v4`.
  - Динамическое inline-предупреждение в JS-интерфейсе `overview.js`.
- [x] **Upgrade paths v1.0.0 → v1.1.1 и v1.0.1 → v1.1.1 пройдены:**
  - Протестировано в изолированных контейнерах, пользовательский UUID сохраняется.
- [x] **Upgrade path v1.1.0 → v1.1.1 пройден (Шаг 1.3):**
  - Проверено: `v1.1.0` с UI обновляется на `v1.1.1` с UI, UUID сохраняется, `[[ladder]]` цел, бинарник обновляется до v1.1.1.
- [x] **Argon проверен (Шаг 1.1):**
  - Протестировано на OpenWrt 24.10.8 с `luci-theme-argon` v3.0.0 (пакет от JerryKuku).
  - Страница управления Sirin открывается корректно, элементы управления и бейджи стилизованы в темном режиме темы.
- [x] **Stable OpenWrt 24.10.x и 25.x проверены (Шаг 1.2):**
  - OpenWrt 24.10.8 (`opkg`) — стабильный релиз, установка и UI работают штатно.
  - OpenWrt 25.12.6 (`apk`) — стабильный релиз 25.x, установка и UI работают штатно.
- [x] **Скриншоты в docs/screenshots/ (Шаг 1.4):**
  - `sirin-ui-bootstrap.png` (Bootstrap Theme)
  - `sirin-ui-argon.png` (Argon Theme)
  - `sirin-ui-openwrt-2020.png` (OpenWrt 2020 Theme)
  - Ссылки добавлены в `docs/ROUTER.md`.
- [x] **Rollback проверен и задокументирован (Шаг 2):**
  - Откат `v1.1.1 -> v1.0.1` протестирован в контейнере: бинарник понижается, UUID сохраняется.
  - Процедура отката и ручной очистки UI задокументирована в `docs/ROUTER.md` (раздел 8.1).
- [x] **Release notes приложены (Шаг 3):**
  - Файл `docs/RELEASE_NOTES_router-v1.1.1.md` сформирован.
- [x] **Announcement готов (Шаг 4):**
  - Файл `docs/ANNOUNCE_v1.1.1.md` подготовлен для рассылки первым тестировщикам.
