# Программа приёмочных испытаний Telegram-бота Sirin (@sirin_crp_bot)

Документ содержит регламент ручной приёмки интерфейса и deep-link механизмов бота после релиза патчей `48051af` и `c7e3808`.

---

## 1. Проверка раздела «📥 Приложения»

Для проверки откройте диалог с ботом **`@sirin_crp_bot`** в Telegram:

1. Отправьте команду `/start` или `/menu`.
2. В появившемся меню нажмите inline-кнопку **`[📥 Приложения]`** (или отправьте `/apps`).
3. Убедитесь, что сообщение содержит актуальные ссылки, а клавиатура состоит из 5 inline-кнопок:
   - `[📱 Android]` `[💻 Windows]`
   - `[🌐 Router]` `[📚 Документация]`
   - `[◀ В меню]`

### Таблица валидации кнопок

| Кнопка | Ожидаемый URL / Действие | Критерий успеха |
| :--- | :--- | :--- |
| **`📱 Android`** | `https://github.com/goodbrat-lab/sirin-vpn/releases/tag/android-v1.3.4` (или свежий `android-*`) | Открывается страница конкретного Android-релиза с APK и GPG-подписью `checksums.txt.asc` |
| **`💻 Windows`** | `https://github.com/goodbrat-lab/sirin-vpn/releases/tag/desktop-v1.0.0` (или свежий `desktop-*`) | Открывается страница Desktop-релиза с инсталлятором `.exe` |
| **`🌐 Router`** | `https://goodbrat-lab.github.io/sirin-vpn/ROUTER.html` | Открывается онлайн-руководство по настройке роутеров OpenWrt |
| **`📚 Документация`**| `https://goodbrat-lab.github.io/sirin-vpn/` | Открывается главная страница документации GitHub Pages |
| **`◀ В меню`** | Callback `my:home` | Сообщение переключается обратно на главное меню клиента |

## 2. Проверка Deep-link импорта ключа

### 2.1 Создание ключа
1. От имени администратора выполните:
   ```text
   /newkey TestDeep 7
   ```
2. Бот присылает карточку с маскированным UUID и кнопкой **`«🕊 Открыть в Сирин»`**.
3. Также проверьте команду `/mykey` или меню **«🔑 Мой ключ»**.

### 2.2 Сценарий А: Приложение «Сирин» установлено на Android
1. Нажмите кнопку **`«🕊 Открыть в Сирин»`**.
2. **Результат:** 
   - Система перехватывает ссылку через App Link (`https://crp.guseynovia.ru/key?uuid=...`) либо по схеме `sirin://key?uuid=...`.
   - Запускается приложение «Сирин».
   - На экране отображается диалог `KeyLinkPrompt`:
     ```text
     Применить ключ из ссылки (…XXXX)?
     ```
   - При нажатии «Применить» ключ сохраняется в хранилище приложения и готов к подключению.

### 2.3 Сценарий Б: Приложение не установлено (или открытие на ПК)
1. Нажмите кнопку **`«🕊 Открыть в Сирин»`** на устройстве без установленного клиента.
2. **Результат:**
   - Открывается браузер по ссылке `https://crp.guseynovia.ru/key?uuid=<UUID>`.
   - Сервер возвращает `HTTP 302 Found` с `Location: sirin://key?uuid=<UUID>`.
   - Пользователь копирует персональный UUID из сообщения бота и устанавливает приложение по ссылкам из раздела «📥 Приложения».

### 2.4 Сценарий В: Windows Desktop
- Поскольку перехват протокола `sirin://` на Windows находится в статусе `TODO` (см. [KNOWN_ISSUES.md](KNOWN_ISSUES.md)), импорт осуществляется копированием UUID из бота и вставкой в поле ввода окна Sirin Desktop.
