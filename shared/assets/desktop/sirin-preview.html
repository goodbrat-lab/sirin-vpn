Сирин — Визуальный элемент "Перо Сирин"

Концепция 4 состояний: Disconnected, Connecting, Connected, Error

Disconnected

Серое перо, наклон 0°, без свечения

Connecting

Connected

Золото + синий акцент, парение ±3px, искры

Error

Красное, наклон 30° (упало), дрожание
