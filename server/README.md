```bash
sudo ./deploy.sh
```

```bash
sudo ./migrate.sh
```

```bash
docker compose logs -f [nginx|xray|sirind|sirinapi|sirinbot]
```

## Telegram-бот (@sirin_crp_bot)

Бот для выдачи и управления ключами доступа (UUID).

Полное руководство по администрированию: [docs/BOT_COMMANDS.md](../docs/BOT_COMMANDS.md).
Интерактивная карта экранов и FSM: [docs/BOT_UX_MAP.md](../docs/BOT_UX_MAP.md).

### Команды:
- `/start` — приветствие и список команд
- `/help` — справка по использованию
- `/mykey` — показать текущий выданный ключ
- `/status` — статистика сервера (только администратор)
- `/newkey <имя> [дни]` — создать новый ключ доступа (только администратор)
- `/list [фильтр]` — список клиентов с пагинацией и статусами (только администратор)
- `/info <имя|uuid>` — карточка клиента с кнопками управления (только администратор)
- `/find <запрос>` — быстрый поиск клиента (только администратор)
- `/rename <старое> -> <новое>` — переименовать клиента (только администратор)
- `/extend <имя|uuid> <дни>` — продлить срок действия (только администратор)
- `/shorten <имя|uuid> <дни>` — сократить срок действия (только администратор)
- `/disable <имя|uuid>` — временно отключить клиента (только администратор)
- `/enable <имя|uuid>` — включить клиента (только администратор)
- `/delete <имя|uuid> [--force]` — удалить ключ с подтверждением (только администратор)

### Синтаксис `/newkey`:
```text
/newkey <имя> [дни]
```
- **Имя:** может содержать пробелы (например, имя и фамилию). Пробелы нормализуются, максимальная длина — 64 символа.
- **Срок действия (дни):** целое положительное число от 1 до 3650 дней (по умолчанию: 30 дней). При указании значения более 3650 дней срок автоматически ограничивается 3650 днями.

#### Примеры:
- `/newkey Марина Иванова 365` — ключ с именем «Марина Иванова» сроком на 365 дней
- `/newkey Тест 7` — ключ с именем «Тест» сроком на 7 дней
- `/newkey Тест` — ключ с именем «Тест» сроком на 30 дней (по умолчанию)

## Откат (если миграция не удалась)
