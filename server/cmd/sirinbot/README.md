# SirinBot (@sirin_crp_bot)

Telegram-бот для выдачи и управления ключами доступа к Sirin VPN.

## Использование команды /newkey

Команда создания нового ключа (доступна только администратору):

```text
/newkey <имя> [дни]
```

### Правила парсинга аргументов:
1. **Имя пользователя:** может состоять из нескольких слов (например, `Марина Иванова`). Пробелы внутри схлопываются, пробелы по краям удаляются. Максимальная длина — 64 символа (UTF-8).
2. **Срок действия (в днях):**
   - Если последний аргумент является целым положительным числом (`1..3650`), он интерпретируется как срок действия ключа в днях.
   - Если указано значение более `3650`, срок автоматически ограничивается значением `3650` (с выводом соответствующего предупреждения).
   - Если последний аргумент не является числом от 1 до 3650, он считается частью имени, а срок выставляется по умолчанию (30 дней).
   - Если аргументы не указаны, бот выводит подсказку по синтаксису.

### Примеры:
- `/newkey Марина Иванова 365` → имя: «Марина Иванова», срок: 365 дней
- `/newkey Иван 90` → имя: «Иван», срок: 90 дней
- `/newkey Тест 7` → имя: «Тест», срок: 7 дней
- `/newkey Тест` → имя: «Тест», срок: 30 дней (по умолчанию)
- `/newkey` → подсказка: «Укажи имя: `/newkey <имя> [дни]`»
