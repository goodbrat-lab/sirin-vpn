# Правила безопасной разработки

## Что НИКОГДА не коммитить
- Пароли, токены, API-ключи
- Приватные SSH-ключи
- Файлы .env любого содержания
- Файлы keystore для подписи APK
- Реальные IP-адреса продакшн-серверов
- Реальные домены и эндпоинты проекта
- Скриншоты с открытыми настройками сервера

## Что можно коммитить
- Исходный код
- Документацию
- Примеры конфигов (с плейсхолдерами типа YOUR_IP_HERE)
- Публичные geo-базы (RU CIDR, домены)

## Правила коммитов
- Перед каждым коммитом: git diff --staged — проверить, что не утекает
- Использовать осмысленные сообщения на английском
- Не коммитить с личных email — использовать анонимный noreply

## Инструменты проверки
- pre-commit hook с trufflehog или gitleaks
- Регулярный аудит: git log -p | grep -i "password\|token\|key"
